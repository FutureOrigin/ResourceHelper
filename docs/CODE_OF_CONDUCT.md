# 社区行为准则

## 我们的承诺

为了让这个项目成为一个对所有人开放、友好的地方，我们承诺：无论年龄、体型、可见或不可见的残障、
族裔、性别认同与表达、经验水平、教育背景、国籍、外貌、种族、宗教、性取向或技术偏好，
参与本项目都不会受到骚扰。

## 我们期望的行为

- 就事论事：讨论代码、行为与证据，不评价人。
- 接受不同意见：技术方案有取舍，先说清约束，再争论方案。
- 主动承认错误并道歉，从错误里学习。
- 尊重维护者的时间：提问前先搜索、先读文档，把复现步骤写清楚。
- 对新手友好：**"这个我也不会"不是缺点，"你连这个都不懂"才是。**

## 不可接受的行为

- 人身攻击、侮辱、贬低、性别歧视、种族歧视或其他歧视性言论；
- 性化的语言或图像、不受欢迎的性关注；
- 公开或私下骚扰、跟踪、威胁；
- 未经许可发布他人的私人信息（真实姓名、住址、邮箱、聊天记录等）；
- 反复无视维护者的边界与决定；
- 其他在专业协作环境中明显不当的行为。

## 关于本项目的特殊约定

- **不要**在本项目的 issue / PR / 讨论区索要或提供 DRM 绕过、付费墙绕过、鉴权绕过的方法。
  这类内容会被直接删除，重复提交会被封禁。
- **不要**提交从第三方商业软件反编译、逆向或复制得到的代码与数据；
  发现仓库里存在这类内容，请立即私下告知维护者。
- 讨论具体站点问题时，请对 URL、Cookie、个人信息做脱敏。

## 适用范围

本准则适用于本仓库的所有空间（issue、PR、讨论、提交信息、代码注释）以及
代表本项目出现在公开场合时的行为。

## 执行

- 违规行为可以私下报告给维护者（通过仓库的 Security 私密报告渠道，或邮件联系维护者）。
- 维护者会审阅并采取适当措施，包括提醒、要求编辑、删除内容、临时或永久禁止参与。
- 维护者有义务对举报人身份保密。
- 维护者本人同样受本准则约束。
