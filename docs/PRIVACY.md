# 隐私说明

ResourceHelper（资源助手）是一个**完全本地运行**的浏览器扩展。这份文档说明它会碰到什么、
不会碰到什么，以及为什么需要那些权限。

## 一句话总结

**扩展不收集、不上传、不出售任何数据。**所有解析、下载与录制都在你的浏览器里完成，
没有服务器，也没有统计上报。

## 扩展会接触到什么

| 数据 | 用途 | 是否离开本机 |
| --- | --- | --- |
| 你当前浏览的页面地址 | 判断用哪份站点适配器、给资源分组 | 否 |
| 页面里的媒体请求（URL、响应头） | 识别可下载资源 | 否 |
| 页面内联的播放器数据（如 __playinfo__） | 解析清晰的轨道信息 | 否 |
| 图片/视频/音频元素的地址与尺寸 | 列出可下载资源 | 否 |
| MSE 播放器喂入的分片（仅在你点"边播边录"后） | 组装成可播放文件 | 否 |
| 下载历史（标题、文件名、状态、体积） | 在"下载"页里回顾 | 否（存在浏览器本地存储） |
| 下载过程中产生的 Blob（仅内存/浏览器 blob 存储） | 在后台完成拼装并交给浏览器下载 | 否（下载完成即释放） |
| 页面自己声明的正文 webfont（仅在你点「提取纯净正文」后） | 解析字形，把字体反爬的私用区码位还原成真字 | 否（只向该字体自己的地址取一次，不带凭据） |
| 页面 DOM 快照与其中引用的图片/样式/字体（仅在你点「保存为单文件 HTML」后） | 组成一个可离线打开的 `.html` 文件 | 否（资源只向它们自己的地址抓取，结果写进你指定的下载目录） |

页面里出现的 URL**可能包含站点生成的临时令牌**（签名、过期时间）。它们会被存进
chrome.storage（标签页级，随标签页关闭清理）与下载历史（本地，最多 300 条 / 30 天），
只用于在你的浏览器里发起下载。扩展不会把它们发到任何第三方。

## 整页快照会多碰什么

"保存为单文件 HTML"是唯一一个**把页面内容整份取出来**的动作，因此单独说明：

- 它读取当前页面（以及嵌进来的 iframe）的 DOM，并把其中引用的图片/样式/字体**再抓一次**
  —— 抓的就是页面本来要显示的那些地址，等同于你重新打开这个页面时浏览器会发的请求；
- 抓取会带上你在这些站点上的 **Cookie**（否则登录可见的图片根本取不到）。
  这是本扩展唯一"带凭证出网"的路径，且只向资源自己的域名发请求；
- 防盗链重试会在**扩展自己发出的请求**上临时补一行 `Referer`（值为当前页面地址），
  规则保留到这一批抓取结束就删除，不影响你正在浏览的页面；
- 产物是一个本地文件：里面有页面正文和这些资源的副本。它不会上传到任何地方，
  但**文件本身可能包含个人信息**（比如你登录后才看得到的页面内容）——请像对待截图一样对待它；
- 默认会删掉页面里的脚本与内联事件，所以产物不会再自己发起网络请求。若你在设置里
  关掉"移除脚本"，产物重新打开时会执行原页面脚本（包括它的联网行为）。

## 扩展不会做什么

- 不收集浏览历史、不注入广告、不做指纹识别；
- 不读取页面表单、密码、Cookie 内容（只会随请求带上浏览器本来就会带的 Cookie）；
- 不绕过 DRM：检测到 SAMPLE-AES / Widevine / PlayReady 等加密内容时明确报错；
- 不修改页面行为：注入的钩子只做旁路记录（不替换 `fetch`/`XMLHttpRequest`，不改请求与响应），
  且默认不启用录制。

## 权限说明

见 [STORE.md](STORE.md) 的权限表。每个权限都有对应的功能，没有"预留"权限。

## 数据删除

- 关闭标签页：该页的资源列表消失（存在 chrome.storage.session）。
- "下载"页 →「清空」：本地下载历史立即清空。
- 卸载扩展：上述本地数据由浏览器一并清除。
